# Mosquitto Notes

This directory can hold optional Mosquitto configuration examples for Raspberry Pi.

For the MVP, Mosquitto is expected to be installed directly on Raspberry Pi:

```bash
sudo apt install -y mosquitto mosquitto-clients
sudo systemctl enable mosquitto
sudo systemctl start mosquitto
```

`mosquitto.conf` is a reference configuration only. The default MVP setup installs Mosquitto directly on Raspberry Pi.
